
# TunePXO COBI

Plugin VST3 de afinación vocal para Windows 10/11 de 64 bits.

## Objetivo

- Compatible con Ableton Live 12 y FL Studio.
- Modo Natural para corrección vocal transparente.
- Modo Hard Tune para afinación rápida y marcada.
- Selección de tonalidad y escala.
- Interfaz oscura moderna.
- Compilación automática para Windows.

## Estado del proyecto

En desarrollo. El motor de afinación vocal todavía debe implementarse y probarse.

## Tecnología

- C++17
- JUCE
- CMake
- VST3
